GREEDY ALGORITHM

Activity Selection

01 / DEFINITION

We have a list of activities, each with a start time and an end time. One person can do only one activity at a time, so the chosen activities must not overlap. We want to select the maximum number of activities. The greedy choice: always pick the activity that finishes first, so the most time is left for the others.

Time O(n log n) (sorting) · Space O(n)

02 / STEPS

  1. Sort all activities by end time, earliest first.
  2. Select the first activity (it ends earliest) and remember its end time.
  3. Go through the remaining activities in order. If an activity starts at or after the last selected end time, select it and update the last end time.
  4. If it starts before the last selected activity ends, skip it.
  5. Count the selected activities. This is the maximum number.
