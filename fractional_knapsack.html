GREEDY ALGORITHM

Fractional Knapsack

01 / DEFINITION

We have items with a value and a weight, and a bag with limited capacity. We want the maximum total value. Items can be broken, so taking a fraction of an item is allowed. The greedy choice: always take the item with the highest value per unit weight first.

Time O(n log n) (sorting) · Space O(n)

02 / STEPS

  1. Calculate the ratio value / weight for every item.
  2. Sort the items by this ratio, highest first.
  3. Go through the items in that order. If the whole item fits, take it all and reduce the remaining capacity.
  4. If it does not fit, take only the fraction that fits (remaining capacity / weight) and stop.
  5. Add the value of everything taken. This is the maximum value.
