Coin Change: Total Combinations

01 / DEFINITION

We have coins of different values (each coin can be used any number of times) and an amount. We want to count in how many different ways the amount can be made. The order of the coins does not matter, so 1 + 2 and 2 + 1 count as one way.

Time O(n × amount) · Space O(n × amount)

02 / STEPS

  1. Make a table dp with n + 1 rows (coins) and amount + 1 columns, filled with 0. Set column 0 to 1, because there is exactly one way to make the sum 0 (take no coins).
  2. For every coin i and every sum j, check if the coin value is less than or equal to j.
  3. If it fits, dp[i][j] = ways without this coin (dp[i-1][j]) + ways using this coin (dp[i][j - coin]).
  4. If it does not fit, copy the value from the row above: dp[i][j] = dp[i-1][j].
  5. The last cell dp[n][amount] is the total number of combinations. If it is 0, the amount is not possible.
